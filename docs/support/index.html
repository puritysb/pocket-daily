SUPPORT

Start with the connection.

Open Pocket Daily on the compatible reader, choose Nearby Sync, then choose Find & Connect in the Apple-platform app.

No reader found

Keep both devices awake and nearby. Confirm Bluetooth and Local Network access, or use the reader's Create Hotspot fallback.

Try the interface

Choose Explore without a reader in the DEVICE card. Demo mode is local and disables transfer and device changes.

Firmware safety

Use only firmware built for the exact hardware profile. Pocket Daily stages the file; installation is confirmed separately on the reader.

Report a problem

Export the in-app connection log or crash report, remove secrets, and attach it to a GitHub issue.

Scope. Support covers Pocket Daily and compatible CrossPoint-based firmware, not factory firmware, manufacturer cloud services, hardware warranty, or physical repair.

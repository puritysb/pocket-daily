## 화면 편집과 공통 내용

Reader settings의 Home/Sleep 편집은 선택한 화면의 미리보기·구성·변경 상태·적용 하나로 끝난다. 카드 선택으로 부모 미리보기를 바꾸지 않는다. Reading도 같은 원칙으로 기기 읽기 옵션만 적용한다.

공통 원본은 Reader settings 안의 간결한 요약 행에서 바로 연다. My cards와 Weather & calendar는 각각 전용 편집 시트/상세 화면을 사용한다. 제목, 해당 원본 미리보기 또는 현재 값, 사용되는 Home/Sleep 범위, 로컬 저장 상태, 하나의 리더 적용 행동을 제공한다. 부모 화면의 적용 바와 중첩되지 않는다. 닫으면 원래 Home/Sleep 선택과 초안·미리보기가 유지된다. 원본 편집을 독립적인 최상위 메뉴로 만들지 않는다.

연결이 없으면 각 활성 편집 작업에서 연결 절차를 열고 같은 작업으로 돌아온다. 내용 편집 시트를 닫아야만 연결할 수 있는 동선은 허용하지 않는다. 기존 초안 저장·기기 신원 확인·충돌 처리·기기 반영 확인은 유지한다. 날씨/일정의 원본 선택과 카드의 로컬 저장을 기기에 반영됐다고 표현하지 않는다.

Reading의 페이지 버튼은 기기 그림 한 곳에 위치와 이전/다음 동작을 표시한다. 별도의 같은 대응표·중복 위치 문장을 제거하고 회전 옵션의 추가 설명은 필요할 때 연다. 기기 모델과 방향은 실제 지원 정보에 따른다. 날씨 출처의 필수 표기는 유지하되 큰 로고나 장문의 안내가 조정을 밀어내지 않게 한다.

## 콘텐츠 보관과 보내기

Library는 앱이 읽을 수 있는 EPUB/TXT/Markdown 및 글의 보관·추가·작성 소유자다. My Reader 첫 화면의 보관함은 기기에 있는 파일과 SD 공간을 보여 준다. 일반 책을 추가/작성하는 두 번째 경로를 만들지 않는다. 보관함의 Add from Library는 서재 선택으로 이어진다. XTC/PDL 등 기기 전용 파일은 필요할 때 여는 명확한 보조 동선에 둔다. 기존 준비 항목은 실제 항목이 있을 때만 전송/복구로 보여 주며 새 파일을 'Previous'라고 부르지 않는다. 폰트 설치·RAM 진단은 Manage reader의 관련 상세에 둔다.

macOS에서는 선택한 책의 보내기 시트 안에서 Reader over Wi-Fi / SD card 대상을 선택한다. SD 대상은 폴더만 선택하며 책을 다시 고르지 않는다. 앱 서재의 원본 바이트와 기존 원자적 복사 원칙을 유지하고, 완료는 SD 복사로 표현한다. 무선 대상의 게시 불확실성·복구 상태를 SD 완료로 덮어쓰지 않는다. 데모는 디렉터리 접근·복사를 하지 않는다. 작업 종료·취소·다른 작업과의 충돌도 명확히 처리한다.

## 연결과 복구

연결은 우선 권장 동선인 같은 Wi-Fi 찾기와 필요한 짧은 안내를 보여 준다. 직접 연결은 다른 방법에서 선택하며 Wi-Fi 전환/인터넷 영향에 대한 기존 명시적 동의를 유지한다. 프로토콜 설명을 모두 펼쳐 놓지 않는다.

결과 미확인 상태에서 다른 리더가 연결되어도 현재 작업 안에서 원래 대상의 연결 절차를 열 수 있다. 잘못 연결된 세션을 끝내고 다른 리더를 찾는 구체적인 행동이 있어야 하며, 자동 전송은 하지 않는다. '진행 중인 작업 보기'는 작업 종류/소유 화면에 맞춰 이동한다. 가져오기면 My Reader의 보관함, 화면 적용이면 해당 편집기, 펌웨어면 Manage reader로 이어진다. 대상 미상 작업을 Manage reader로 무조건 보내지 않는다.

## 탐색과 설정

My Reader는 모든 플랫폼에서 기기 상태·작업·보관함을 한 화면으로 모은다. 별도 Overview·On Reader·Screens·Reading·Device 메뉴를 두지 않는다. 기기 카드의 Reader settings로 편집하며, Reader options → Manage reader로 연결·업데이트·진단을 연다. 앱 설정은 별도 보조 진입점으로 앱 외관과 이어 읽기 정책을 소유한다.

## 완료 검사

1. Home에서 공통 카드 편집을 열어도 부모 대상/미리보기가 바뀌지 않으며 활성 편집기에는 적용 하나만 있다.
2. Home과 Sleep의 날씨/일정 원본은 동일한 편집기로 연결된다. 닫기·연결·복귀에도 초안과 선택이 보존된다.
3. Reading에서 세로/가로와 X3/X4 버튼 동작을 하나의 그림으로 확인한다.
4. 서재에서 선택한 책을 무선 또는 SD로 보내며 대상 선택에서 책을 잃지 않는다. SD 복사는 임시 폴더에서 바이트 보존·원자적 게시·실패 처리를 검증한다. 물리 SD 수용은 별도 보고한다.
5. 전송 결과 미확인·다른 리더·다른 작업 대기에서 실행 가능한 복구 행동과 정확한 목적지가 있다.
6. 내 리더의 메뉴 반복, 기기 보관함의 RAM·폰트·일반 책 작성 중복을 제거한다.
7. 양 플랫폼 빌드, 변경 관련 회귀 테스트, 실제 Mac 화면 탐색, iPhone/iPad UI 검사 및 전체 스토어 캡처를 실행한다. 기능 검증과 UX 시나리오 검토를 구분해 보고한다.

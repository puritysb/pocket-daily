Pocket Daily는 호환되는 포켓형 전자종이 리더를 위한 개인정보 보호 중심의 로컬 스튜디오입니다.

리더의 홈과 슬립 화면을 원하는 대로
홈에 보여줄 페이지와 순서(이어 읽기, 학습 카드, 제공 카드, 사용량 요약)를 고르고, 날씨 패널 위치를 정하고, 잠든 동안 보여줄 Daily Brief를 구성합니다. 미리보기는 리더의 레이아웃 코드가 예시 콘텐츠로 그린 화면이며, Send 한 번으로 펌웨어를 다시 설치하지 않고 리더에 저장됩니다.

전자종이에 맞는 학습 카드
글과 이미지가 들어간 카드를 최대 세 장까지 편집하고, 보내기 전에 리더 해상도로 확인합니다. 초안은 기기에 저장되고, Send할 때마다 같은 연결에서 리더 화면이 갱신됩니다.

내 콘텐츠를 기기로 직접 전송
지원되는 책, Pocket Daily 학습 팩, 호환 펌웨어를 직접 로컬 연결로 전송합니다. Mac에서는 SD 카드로 파일을 복사할 수도 있습니다. 전송 파일은 Pocket Daily의 클라우드 서비스를 거치지 않습니다.

더 안전한 기기 관리
리더 설정을 조정하고, 명확한 호환성 경고를 확인한 뒤에만 펌웨어 파일을 준비합니다. 실제 설치는 리더에서 다시 확인해야 시작됩니다.

처음부터 로컬 우선
Pocket Daily 계정, 광고, 분석 도구, 클라우드 중계가 없습니다. 검색과 전송은 Bluetooth와 로컬 네트워크를 사용하며 파일은 사용자의 Apple 기기, 리더와 선택한 저장소 사이에만 남습니다.

연결 전에도 체험
내장 데모 모드에서 리더 없이 예시 콘텐츠로 편집기를 둘러볼 수 있습니다. 데모 모드는 파일을 보내거나 기기 설정을 변경하지 않습니다.

호환성 안내
실제 전송과 설정에는 Pocket Daily 또는 호환 CrossPoint 기반 펌웨어를 실행하는 별도 구매 X3/X4 계열 리더가 필요하며, 홈·슬립 편집에는 이 설정을 저장하는 Pocket Daily 펌웨어가 필요합니다. 제조사 기본 펌웨어와 클라우드 서비스는 지원하지 않습니다. Pocket Daily는 독립 오픈소스 프로젝트이며 어떤 리더 제조사나 CrossPoint Reader 프로젝트의 제휴·후원·보증을 받지 않습니다.

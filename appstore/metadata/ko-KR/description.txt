Pocket Daily는 호환되는 포켓형 전자종이 리더를 위한 개인정보 보호 중심의 로컬 컴패니언입니다.

연결한 리더를 그대로 확인
Pocket Daily 근거리 동기화(Nearby Sync)로 연결하면 동기화 직전에 캡처한 전자종이 화면을 앱에서 그대로 보여줍니다. 리더가 없을 때는 예시 콘텐츠를 실제 화면처럼 꾸미지 않고 X3/X4 하드웨어 프로필임을 분명히 표시합니다.

내 콘텐츠를 기기로 직접 전송
지원되는 책, Pocket Daily 학습 팩, 호환 펌웨어를 직접 로컬 연결로 전송합니다. Mac에서는 SD 카드에 파일을 바로 준비할 수도 있습니다. 전송 파일은 Pocket Daily의 클라우드 서비스를 거치지 않습니다.

더 안전한 기기 관리
리더 설정을 확인하고, 절전 중 Daily 카드를 유지하며, 명확한 호환성 경고를 확인한 뒤에만 펌웨어 파일을 준비합니다. 실제 설치는 리더에서 다시 확인해야 시작됩니다.

처음부터 로컬 우선
Pocket Daily 계정, 광고, 분석 도구, 클라우드 중계가 없습니다. 검색과 전송은 Bluetooth와 로컬 네트워크를 사용하며 파일은 사용자의 Apple 기기, 리더와 선택한 저장소 사이에만 남습니다.

연결 전에도 체험
내장 데모 모드에서 리더 없이 컴패니언 인터페이스를 둘러볼 수 있습니다. 데모 모드는 파일을 보내거나 기기 설정을 변경하지 않습니다.

호환성 안내
실제 전송과 설정에는 Pocket Daily 또는 호환 CrossPoint 기반 펌웨어를 실행하는 별도 구매 X3/X4 계열 리더가 필요합니다. 제조사 기본 펌웨어와 클라우드 서비스는 지원하지 않습니다. Pocket Daily는 독립 오픈소스 프로젝트이며 어떤 리더 제조사나 CrossPoint Reader 프로젝트의 제휴·후원·보증을 받지 않습니다.
